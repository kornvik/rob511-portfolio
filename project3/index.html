Project 3

Forward Kinematics
+ Live Visualization

I wrote a small Rust runtime that reads a URDF, computes forward kinematics for every link, and streams the 4×4 matrices over a rosbridge-style TCP gateway. A three.js page on the other side draws the arm live. For the demo I built a 6-DOF arm and taught it to wave at the camera.

Rust three.js URDF rosbridge TCP/JSON
Robot
A 6-DOF arm I wrote by hand in URDF: waist, shoulder, elbow, and a 3-DOF wrist.
Choreography
A four-state FSM: home, arm up, wave right, wave left. The waist leans a bit each way so the body turns too.
How it's drawn
A three.js page over a WebSocket (via a tiny Python TCP relay). It subscribes to /xform_world and drops each link's 4×4 straight into a group with Matrix4.fromArray.
